# BARIQ – Glaucoma Detection System

BARIQ is an AI-based system for early glaucoma detection using retinal fundus images.

The system integrates:

- Deep Learning model for glaucoma classification
- Mobile application for capturing retinal images
- 20D lens attachment to improve image quality

## Project Components

1. Dataset
2. Image preprocessing
3. Model training
4. Model evaluation
5. Mobile application integration

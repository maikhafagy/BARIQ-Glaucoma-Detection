BARIQ System Architecture

1. Image Capture
Retinal fundus images are captured using a smartphone with a 20D lens attachment.

2. Image Preprocessing
Images are resized and normalized.

3. Deep Learning Model
Transfer learning CNN model used for glaucoma classification.

4. Prediction
Model predicts:
- Glaucoma
- Normal

5. Visualization
Grad-CAM used to highlight important regions in the retina.
